# Product Direction

## Positioning

Godot Gamestudio is not another Godot copilot. It is a production loop: specialists create, independent reviewers challenge, and milestones pass only when verified in the running game.

The advantage is not a larger prompt library. It is controlled delegation, reviewer independence, resumable evidence, and fewer confident false approvals.

## Community

Community remains open source and includes the complete safety and correctness loop: Supervisor, core roles, state and evidence gates, Godot CLI verification, portable harness adapters, and public smoke benchmarks.

## Proposed Pro

Pro should sell automation rather than withholding correctness:

- Automated screenshot and video capture
- Visual regression, animation continuity, and art-consistency reports
- CI and GitHub milestone reports
- Benchmark history and project dashboards
- Advanced accessibility, performance, audio, multiplayer, and release packs
- Supported GodotIQ adapter for users with their own GodotIQ license

The working message is: **The studio workflow is free. Automated visual proof is Pro.**

Do not fix pricing before beta evidence exists. Test one-time Creator prices around EUR 29, EUR 39, and EUR 49 after the visual test lab demonstrates measurable gains.
