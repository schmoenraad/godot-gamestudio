# Sprite Skill Lab

This folder is the working area for testing and tuning the Godot Gamestudio sprite workflow.

- `inputs/`: source references, generated raw sheets, and task briefs
- `outputs/`: processed frames, atlases, contact sheets, and Godot-ready assets
- `reports/`: grader output and review notes
- `fixtures/`: small deterministic sprite fixtures for tests

Keep experimental files here until they are promoted into `scripts/`, `tests/`, `evals/`, or `skills/`.
