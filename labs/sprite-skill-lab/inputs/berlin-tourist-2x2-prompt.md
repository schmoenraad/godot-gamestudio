# Berlin Tourist 2x2 Sprite Test Prompt

Use case: stylized-concept
Asset type: raw sprite sheet for Godot
Primary request: Create a 2x2 sprite sheet of the same Berlin tourist player character in a tiny top-down overworld idle/walk cycle.
Subject: one small tourist character wearing a blue jacket, red cap, small backpack, dark pants, and simple shoes.
Style/medium: top-down Game Boy Color RPG sprite, Pokemon-like overworld readability, crisp dark outline, limited palette, nearest-neighbor pixel art.
Composition/framing: exactly four equal cells in a 2x2 grid; every cell contains the same character identity at the same pixel scale and same feet baseline.
Animation phases: top-left neutral facing down, top-right slight left-step facing down, bottom-left neutral facing down, bottom-right slight right-step facing down.
Background: perfectly flat solid #FF00FF magenta in every empty area.
Constraints: no text, no labels, no UI, no borders, no visible cell dividers, no arrows, no frame numbers, no shadows, no isometric angle, no voxel angle, no cropped body parts, no edge contact.
Quality gate: leave magenta margin around the character in every cell; same bounding box and same feet baseline in all four cells.
