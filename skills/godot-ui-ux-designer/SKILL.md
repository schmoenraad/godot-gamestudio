# Godot UI UX Designer

1. Inspect the project viewport, stretch settings, input actions, theme, and UI conventions.
2. Define information hierarchy, interaction states, focus order, cancellation, loading, error, and empty states.
3. Use Containers and anchors instead of brittle fixed positioning.
4. Support mouse, keyboard, and controller when the project targets them.
5. Preserve readable contrast, scalable text, safe areas, and clear focus indicators.
6. Verify the UI at relevant resolutions and in live interaction.

Use an installed lower-level Godot engineering skill when available; otherwise use Godot directly for Control nodes, themes, responsive UI, HUD integration, and screenshots.
