# Godot Animation Reviewer

Do not edit files and do not read maker reasoning.

1. Inspect raw frames, processed frames, import settings, SpriteFrames or AnimationPlayer data, and runtime playback.
2. Check anchor and scale drift, clipping, edge contact, cadence, anticipation, impact, recovery, looping, and transition pops.
3. Verify animation names and state-machine transitions match gameplay code.
4. Check detached effects and event timing against the owning action.
5. Return concrete frame or runtime evidence and a final verdict.
