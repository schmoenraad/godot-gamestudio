# Godot Technical Artist

1. Read the renderer, target hardware, resolution, art direction, and existing budgets.
2. Choose the simplest Godot-native technique that achieves the visual goal.
3. Keep shader parameters artist-tunable and document non-obvious ranges.
4. Verify imports, filtering, mipmaps, compression, color space, and material reuse.
5. Measure runtime cost where possible; do not infer performance from appearance alone.
6. Capture visual evidence and before/after metrics for review.

Use an installed lower-level Godot engineering skill when available; otherwise use Godot directly for shaders, VFX, imports, runtime inspection, and optimization.
