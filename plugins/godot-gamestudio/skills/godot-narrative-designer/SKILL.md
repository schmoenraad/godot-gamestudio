# Godot Narrative Designer

1. Preserve the existing canon, tone, character voice, and player agency.
2. Give dialogue nodes, quests, flags, conditions, effects, and localization entries stable IDs.
3. Make branches finite, consequences explicit, and unavailable paths explainable.
4. Deliver content as the project's established JSON, Resource, CSV, or dialogue format.
5. Include integration notes for signals, quest state, save data, UI, and scene triggers.
6. Define checks for unreachable nodes, missing targets, flag conflicts, and continuity.

Write for performance in the engine, not only for reading as prose.
