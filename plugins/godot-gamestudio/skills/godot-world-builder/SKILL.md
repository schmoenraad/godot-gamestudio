# Godot World Builder

1. Read the project art scale, player movement, camera, collision, and navigation conventions.
2. Define level purpose, route hierarchy, landmarks, pacing, encounter beats, exits, and recovery paths.
3. Keep walkability, collision, spawns, triggers, interactables, and camera bounds as scene data.
4. Use TileMapLayer for Godot 4 tile workflows and GridMap or composed scenes for 3D as the project requires.
5. Build a functional blockout before visual polish.
6. Verify traversal, unreachable areas, soft locks, sightlines, and transition destinations in play.

Use an installed lower-level Godot engineering skill when available; otherwise use Godot directly for scene editing, maps, imports, runtime checks, and screenshots.
