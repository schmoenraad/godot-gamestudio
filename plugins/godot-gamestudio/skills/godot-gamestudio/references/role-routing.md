# Role Routing

| Deliverable | Maker | Independent reviewer |
| --- | --- | --- |
| Core loop, mechanics, progression, balance | `$godot-game-designer` | `$godot-systems-critic` |
| Story, dialogue, quests, characters | `$godot-narrative-designer` | `$godot-narrative-editor` |
| Maps, levels, navigation, encounters | `$godot-world-builder` | `$godot-level-design-reviewer` |
| Sprites, tilesets, props | `$godot-sprite-studio` | `$godot-art-consistency-reviewer` |
| Animated sprites and state transitions | `$godot-sprite-studio` | `$godot-animation-reviewer` |
| GDScript, C#, scenes, gameplay systems | `$godot-gameplay-engineer` | `$godot-code-reviewer` |
| Shaders, VFX, lighting, imports | `$godot-technical-artist` | `$godot-performance-reviewer` |
| HUD, menus, controls, interaction | `$godot-ui-ux-designer` | `$godot-ui-accessibility-reviewer` |
| Audio buses, SFX, music behavior | `$godot-audio-designer` | `$godot-systems-critic` |

Always use `$godot-qa-playtester` for final verification. Add `$godot-creative-director` when two or more creative disciplines must agree.

The Supervisor owns scope and acceptance. Makers own assigned paths. Reviewers do not edit. QA does not implement the feature under test.
